# 집으로 — 동탄역 귀가 버스 웹 데모

설치나 로그인 없이 사용자별 목적지 설정, 도보 조건에 따른 추천, 놓친 버스 제외·대안 추천, 승차 경로 상세, 화면/브라우저 알림을 체험하는 정적 웹 앱입니다.

## 실행 및 검증

`npm start` 후 http://localhost:4173 접속. `npm test`로 추천 로직을 검증합니다. 외부 패키지 설치는 필요하지 않습니다(Node.js, Python 3 사용).

## 데이터와 알림 범위

모든 노선 ID, 승차장, 시간은 가상입니다. 세 지역별 예시 경로만 제공하며, 임의 목적지 이름을 실제 주소로 해석하지 않습니다. 실제 서비스에는 목적지 검색, 실제 정류장/노선 데이터, 서버 측 교통 API 연동이 필요합니다. API 실패 시 시연 데이터를 실시간 정보처럼 대체해서는 안 됩니다.

‘1분 진행’으로 19:00부터 시연 시간을 움직입니다. 추천은 버스 도착이 승차장 이동+1분 안전 여유 이상이고 하차 후 도보 조건을 만족하는 경로 중 전체 도착 시간이 가장 빠른 경로입니다. 알림은 켜진 상태에서 이동 시간+추가 여유 시간에 도달하면 경로별 한 번 발생합니다. 브라우저 권한 거절/미지원 시 화면 알림으로 동작합니다. 백그라운드 푸시, 화면 잠금, 페이지 종료 후 알림은 구현되지 않았습니다.

목적지 설정만 localStorage에 보관합니다. 시연 상태와 알림 권한 활성화 상태는 저장하지 않습니다. 공개 배포 시 dist 폴더를 정적 호스팅하고 로그아웃 상태에서 확인합니다.

## 동탄역 에일린의뜰
목적지 선택에 동탄역 에일린의뜰을 추가했습니다. 경기도교육청 2025년 11월 이산고등학교 교통편 안내의 206·H2 → 에일린의뜰 하차를 참고 후보로 제공하고 출처를 표시합니다. 현재 운행, 승차 위치·방향 및 실시간 도착은 검증되지 않아 순위나 예상 시간을 생성하지 않습니다.

## 내 위치
사용자 버튼 클릭으로 브라우저 Geolocation API를 호출합니다(HTTPS/localhost). 권한 거절, 미지원, 위치 불가, 시간 초과, 낮은 정확도, 오래된 결과를 처리합니다. 취소 후 늦게 도착한 응답은 무시합니다. 좌표는 저장소·서버·WebMCP 응답으로 보내지 않습니다. 사용자가 지도 링크를 눌렀을 때만 Google에 좌표를 전달하며 화면에 이를 안내합니다.

동탄역까지의 길찾기는 Google 지도에서 열립니다. 국내 도보 경로 제공 여부는 지도 서비스에 따라 달라집니다. 승차장 좌표와 경로 API 미연동으로 도보 시간을 GPS에서 자동 계산하지 않습니다. 출발 위치 선택과 직접 입력한 동탄역까지 남은 이동 시간을 기존 시연 승차장 이동 시간에 더해 추천합니다. 이동 시간은 세션 메모리에만 유지합니다. 실제 도착 정보가 없는 에일린의뜰 경로의 실시간 추천/알림 제한은 유지됩니다.

## 시니어 음성 도우미
큰 글씨 기본 모드, 큰 질문 버튼, 한국어 TTS 안내·다시 듣기·속도 조절·중지와 Web Speech 음성 질문을 제공합니다. 버스 추천/도착/승차 위치/도움말/현재 위치/목적지 변경/놓친 버스를 처리하는 규칙 기반 도우미입니다. 생성형 AI 모델 또는 외부 LLM 에이전트는 연결되지 않았습니다. 도착 정보가 없는 구간은 음성으로도 이를 명시합니다. 시연 데이터 안내는 반드시 시연임을 먼저 알립니다.

음성 인식은 한 문장씩 최대 15초, 사용자 버튼 클릭 후 시작합니다. 브라우저 지원 여부·권한 거절·네트워크 실패·무음 등에 큰 버튼/텍스트 안내를 제공합니다. 브라우저가 음성을 제공업체 서버로 전송할 수 있다는 점을 화면에서 안내합니다. 서비스는 녹음/인식 문장을 저장하지 않습니다. TTS 또한 기기의 설치 음성과 브라우저에 따라 지원이 달라집니다. 원격 음성이 사용되면 안내 문구가 브라우저 음성 서비스에서 처리될 수 있으므로 정확한 좌표나 사용자가 입력한 집 이름은 읽어 보내지 않습니다.

음성 명령으로 목적지 변경/버스 제외 요청 시 확인 버튼을 요구합니다. 늦게 도착한 인식 결과를 무시하고 조건 변경 시 이전 안내를 중단합니다. 탭이 숨겨지거나 페이지가 종료되면 녹음·음성 재생을 중단합니다. 시연 알림 음성 읽기는 사용자가 선택해야 켜집니다. 실제 기기 마이크·스피커 테스트는 별도 필요합니다.
